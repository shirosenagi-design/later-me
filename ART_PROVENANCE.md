## Owner-attested creation history

The project owner, 鮫洲ネオ, used images found through Google Image Search as
visual references for atmosphere and direction. Those references were provided
conversationally as inspiration. OpenAI / ChatGPT image generation then created
new visual material specifically for CALL-E, which was cropped, separated, and
processed into the nine runtime assets listed above.

The original Google Image Search reference files are not included in this
repository and are not the runtime assets. This provenance is based on the
owner-attested development history because the final PNG metadata does not
preserve generation provenance.
